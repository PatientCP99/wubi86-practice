## 3. 最近这一轮做了什么（细节看 commit message，不重复）

1. **简码归属 bug**（`80bdc07`）：源码表给 25 个一级简码字的 `stem` 列写的是它自己的前两码，而那其实是**别人**的二级简码。这些曾被当成二级简码补进数据 → 敲 `aa`+空格 上屏 `工` 而不是 `式`（10 个码会打错字）。修法：补 stem 简码时跳过已有一级简码的字；判据是源码表里**有没有那一行的独立记录**（`地 fb` 有独立行 → 保留；`工 aa` 只有 stem → 剔掉）。剔 14 条，`single` 75020 → 75006，二级码 630 → 616。

## 8. 踩过的坑（省你时间）

1. **`file://` 下 ES module 与 `fetch` 全废**（origin 为 null）——只能用经典 `<script>` + `window.*` 全局，数据是 `data/*.js` 而不是 JSON。
2. **扩展 A/B 汉字是代理对**——文本遍历**一律** `Array.from()` / `for...of`，禁止 `str.length` / `split("")` / `str[i]`。
3. **PowerShell 传中文命令会被旧代码页截断**（报"字符串缺少终止符"）——写 commit message 用 `write` 工具落文件 + `git commit -F`，并去掉 BOM、统一 LF。
4. **`git commit -F` 必须显式写 pathspec**（`git commit -F f -- a.js b.js`），否则会连带提交用户自己 `git add` 暂存但未提交的文件。
5. **`git show > file` 在 PowerShell 里会写坏编码**——用 `[System.IO.File]::WriteAllLines($p, (git show X), UTF8Encoding($false))`。
6. **正则解析 `data/rootmap.js` 要锚死**：文件里 `humanVerified.items` 也带 `key` 字段，松正则会错位（曾导致 `g` 键整个丢失、12 个码位分类算错）。`fetch_rootunits.py` 已加硬断言（25 个键必须全解析到 + 键名字必须在自己键的字根里）。
7. **`stats.js` 写盘时机**：`recordCommit`/`recordHint` 走 1.2 秒节流 `saveSoon()`；离开页面（`beforeunload`/`pagehide`/`visibilitychange`）走 `flush()`；故事断点走 `setStoryCursor` 立即写盘。
8. **`wubi-core.js` 的 `seek(n)` 是精确续打定位**，不要用 `skip()` 循环代替（`skip` 按最长匹配词前进，会越过一个字，把没打过的字标成已打）。
9. 用户会**自己**动 git（提交 README、push、暂存文件），动手前先 `git status` 看清，别假定远端落后。
